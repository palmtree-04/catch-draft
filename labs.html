Mod the game. Ship it.

Pirate Radio Labs is the unoffical File Explorer for Knockout City. Explore the game's files, draft custom content, and build/ship it to the Pirate Radio Launcher's Mods Library.

Download Labs Betav0.5.0-beta.3

Also for: Linux .deb Linux .rpm

What's in the lab

All the tools for tinkering are here:

Browse game files

The depths of the archives are instantly accessible; just tell Labs where to look and start exploring right away.

Preview everything

Inspect models, materials, textures, and get relevant previews on file attributes. Need a better look at certain files? Export them!

Test, then publish

Package your work as a draft to access it in the Pirate Radio Launcher Mods Library. When it's ready, publish it to the launcher's Mod Store!.

The pipeline

Client-side modding made easy.

  1. Explore

    The entire file system is explorable. Find files, add them to your draft, and get creative!

  2. Build

    Export relevant files from the directory, build your replacements, and override files from within your draft.

  3. Publish

    Add finishing touches and ship it directly to the Pirate Radio Launcher's Mod Store, where anyone and everyone can add it to their Mods Library.

  4. Play

    Players install it from Pirate Radio Launcher and see it in game.
